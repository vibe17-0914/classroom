# 📈 우리 반 경제교육 모의 주식 체험 플랫폼 (`Classroom Stock`)

초·중·고등학생들의 실전 경제/금융 교육을 위한 모의 주식 체험 웹 애플리케이션입니다.  
실제 KOSPI 시총 상위 20개 종목의 실시간 시세를 반영하며, 선생님(학급 관리자)이 수업 전용 커스텀 종목을 개설하고 가격을 직접 조정하거나 자동 랜덤 등락 기능을 켤 수 있습니다.

---

## ✨ 주요 기능

### 1. 📊 실시간 KOSPI 시세 연동 & 모의 주식 거래
- **KOSPI 상위 20개 대표 종목** 실시간 주가 및 30일 가격 차트 연동.
- 학생별 초기 가상 자본금(시드머니) 지급 및 매수/매도 실시간 주문 체결.
- 보유 주식 수익률, 총 평가금액, 실시간 학급 랭킹 리더보드 제공.

### 2. 🎲 커스텀 종목 & 자동 랜덤 가격 변동 시스템
- 선생님이 우리 반 전용 종목(예: '우리반 매점', '급식 연구소' 등)을 자유롭게 추가.
- **주기적 자동 랜덤 변동**:
  - `[v] 자동 변동 켜기` 체크 시, 설정한 **분(Minute) 주기**마다 자동으로 가격 등락.
  - 1회 변동폭(%) 및 주기(분)를 관리자가 자유롭게 지정 가능.
  - 주가 변동 시 교육용 뉴스(실적 발표, 신제품 호평, 원자재가 급등 등) 자동 발생.
- **관리자 직접 가격 조정**: +5%, +10%, 상한가(+30%), 하한가(-30%) 원클릭 퀵 버튼 및 직접 가격 입력 지원.

### 3. 👩‍🏫 선생님 전용 관리자 모드
- 비밀번호(`admin`) 기반 관리자 모드 전환.
- **학생 명단 관리**:
  - 개별 추가 및 "1. 김철수 \n 2. 이영희" 형식의 일괄 붙여넣기 등록.
  - 학생별 보유 잔고 수정 및 학급 전체 계좌 일괄 리셋.
- **종목 관리**:
  - 실시간 종목 검색 추가, 커스텀 종목 생성/삭제, KOSPI 기본 20종목 복원 기능.

## 🚀 빠른 시작 (실행 방법)

### 요구 사양
- [Node.js](https://nodejs.org/) (v18 이상 권장)

### 원클릭 실행 (Windows)
프로젝트 루트 폴더의 `run.bat` 파일을 더블클릭하면 자동으로 백엔드와 프론트엔드가 실행됩니다.

```bash
run.bat
```

- **브라우저 접속 주소**: [http://localhost:5000](http://localhost:5000)
- **선생님 관리자 비밀번호 기본값**: `admin`

---

## 🛠 기술 스택
- **프론트엔드**: React 18, Vite, Lucide Icons, Vanilla CSS (다크 핀테크 테마)
- **백엔드**: Node.js, Express, 네이버 금융 Open API Proxy
- **데이터베이스**: JSON 파일 기반 로컬 영속 저장소 (`server/data/store.json`)
